# zis图文内容卡片生成器

从七月安妮公众号长文中选择一条精简观点，调整文字、背景和卡片样式，然后导出适合图文平台发布的 PNG。

## 当前内容库

- 101 篇公众号原文进入最终内容库
- 156 条经过二次质量过滤的可编辑精简内容卡片
- 7 个分类：选择与命运、身心觉察、生活思考、创作表达、自由与商业、亲密关系、认识自己
- 需要核实的数据、收益和理论判断保留风险提示
- 原项目演示内容、外部素材和模拟互动数据均已移除

## 使用

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

浏览器默认打开 `http://localhost:5173`。

## 功能

- 搜索、分类和随机选择安妮公众号精简内容
- 选择后继续编辑，或切换到完全自由编辑
- 白色、黑色两种卡片
- 3:4 背景图成品与纯内容卡片
- 内置背景、本地上传和网络图片
- 拖动、缩放和重置卡片位置
- 自动生成一句发布文案和三个话题标签
- 一键导出 PNG，正文全程保留在本地浏览器
